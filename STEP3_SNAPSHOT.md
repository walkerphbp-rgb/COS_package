## Done design facts
- Policy: https only, no userinfo, default port only, no IP literals, exact hostnames. Effective allowlist = operator list (`COS_RESEARCH_HOSTS`, empty = research DISABLED) AND format `evidence.source_domains` when non-empty. Neither widens the other.
- Every hop re-validated + re-resolved; ANY private/special DNS answer refuses; connection pinned via `lookup`; remote address compared after connect (DEST_MISMATCH). Max 3 redirects, 1 MiB download, 15 s whole-call timeout (ref'd timer: `AbortSignal.timeout` is unref'd and lets Node exit silently).
- Hashes: `rawSha256` = downloaded bytes (<= maxBytes); `textSha256` = extracted text actually given to the model (<= maxModelChars). Download truncation and model truncation reported separately. A hash alone does not allow evidence reconstruction, so the text is stored too.
- `parseResearch`: `absent` (research undefined -> legacy seed route, label demo/legacy) vs `invalid` (null, array, empty sources, unknown field, bad URL -> 400, never falls back) vs `ok`. Duplicate URLs collapse by canonical URL, first wins, ids S1..Sn deterministic.
